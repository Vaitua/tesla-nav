# Tesla Nav

Navigation 3D pour le navigateur de la Tesla : carte moderne (jour/nuit automatique), guidage vocal, limitations de vitesse, bornes de recharge (registre IRVE), vue satellite, météo en direct, favoris.

100 % statique (HTML/CSS/JS), sans clé d'API. Services utilisés : OpenFreeMap, Valhalla (OSM), Géoplateforme IGN, Photon, Open-Meteo, ODRÉ (IRVE), Esri World Imagery.

Test sans GPS : ajouter `?sim=50&from=1.35,43.43` à l'adresse (conduite simulée à 50 km/h).
